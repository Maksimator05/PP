# Допущения

- Основная целевая переменная - `sales_amount`, дополнительная - `sales_quantity`.
- Неделя начинается в понедельник.
- Если исходный X5-файл не содержит категорий, категория восстанавливается через хэш SKU.
- Если исходный файл не содержит магазин, используется `store_unknown`.
- Промо-тексты могут быть синтетически сгенерированы, если в датасете нет текстового поля.
- Синтетический fallback не считается реальным X5 RetailHero и явно отмечается в логах, документации и manifest-файле.
- В текущей среде использован синтетический fallback, потому что публичные источники X5 недоступны.
- CatBoost используется при наличии зависимости; иначе применяется `HistGradientBoostingRegressor`, чтобы проект оставался запускаемым локально.
