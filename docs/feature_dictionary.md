# Словарь признаков

- `sales_amount_lag_N`: продажи N недель назад; источник - `weekly_sales`; риск утечки низкий, используется только прошлое.
- `sales_quantity_lag_N`: количество продаж N недель назад.
- `sales_amount_roll_mean_N`: средние продажи за N прошлых недель со сдвигом на одну неделю.
- `sales_amount_roll_std_N`: волатильность продаж за N прошлых недель со сдвигом.
- `weekofyear`: номер недели целевой даты.
- `month`: месяц целевой даты.
- `quarter`: квартал целевой даты.
- `is_holiday`: флаг праздничной даты по встроенному календарю.
- `is_promo_week`: агрегированный промо-флаг текущей недели.
- `promo_text_len`: длина промо-текста.
- `promo_word_count`: число слов.
- `promo_discount_pct`: максимальная скидка, найденная regex.
- `promo_has_bundle`: найдено предложение набора.
- `promo_has_new`: найден маркер новинки.
- `promo_has_sale`: найден маркер скидки или распродажи.
- `promo_positive_words`: число позитивных слов из встроенного словаря.
- `promo_negative_words`: число риск-слов из встроенного словаря.
- `store_code`, `category_code`: стабильное кодирование категориальных полей для локальных моделей.
